## Week 1 - History
- Writing started ~5,000 years ago in Mesopotamia: cuneiform, wedge-shaped marks pressed into clay tablets
- Early writing was practical: receipts and records (e.g. barley and beer)
- Babylonians used a positional base-60 number system; Romans used subtractive notation (MCM = 1900)
- One writing system can be used by many languages
- The Epic of Gilgamesh (~4,000 years ago) is one of the earliest works of literature

## Week 2 - Bits and Bytes
- A bit is a binary digit (0 or 1); a byte is 8 bits
- 8 bits unsigned: 0 to 255; signed: -128 to 127
- RAM is volatile (loses data without power); SSD/HDD are non-volatile
- The ASCII table maps numbers to characters, e.g. 65 = 'A'; control codes like newline are non-printable
- Text files are bytes interpreted as characters; binary files are not meant to be read as text

## Week 3 - Text Structure
- Markdown: `# Title`, `## Subtitle`, `_italic_`, `**bold**`, lists with `-` or `*`
- Rendering = converting raw markup text into a formatted view
- HTML is more verbose: `<h1>`, `<p>`, `<ul>`, `<li>`, `<strong>`
- Escaping: `\#` shows a literal `#` in Markdown; in HTML use `&lt;` `&gt;` `&amp;`
- JSON stores structured data as `{"key": "value"}`

## Week 4 - Keyboards and Editors
- Modifier keys (Ctrl, Shift, Alt) change what other keys do
- Touch typing reduces fatigue and cognitive load
- Word processors (MS Word) are not the same as text editors (Notepad, VS Code, Vim)
- Vim is a command-line editor that requires learning commands; exit without saving with `:q!`
- Learn keyboard shortcuts: Ctrl+F find, Ctrl+Z undo, Home/End, Ctrl+arrows to jump by word

## Week 5 - Command Line (CLI)
- `pwd` prints the current directory, `ls` lists files, `cd` changes directory
- `.` is the current directory, `..` is the parent, `~` is the home directory
- `cat` prints a file, `less` views it interactively, `mkdir` creates a folder, `cp`/`mv` copy and move
- `grep` searches text by pattern; `>` redirects output to a file and `|` pipes it to another command
- `ssh` connects to a remote computer; `scp`/`sftp` transfer files securely
- CLI advantages: faster for some tasks, easy to automate with scripts, works well remotely with low bandwidth
